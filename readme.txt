ALBANIAN WOMEN'S ALLIANCE (AWA) — GODADDY CPANEL WEBSITE

WHAT'S INCLUDED
- index.html: complete bilingual website (English / Albanian)
- styles.css: responsive styling for desktop, tablet and mobile
- script.js: language switcher, mobile navigation and interest form
- assets/awa-logo.jpg: cropped AWA logo artwork from the branding image you previously supplied

BEFORE YOU PUBLISH
1. Open script.js in a text editor.
2. Find: contactEmail: "ADD-YOUR-AWA-EMAIL-HERE"
3. Replace it with the official email address where AWA should receive membership and contact inquiries.
4. Save the file.

The form currently opens the visitor's email app (mailto). It does not store submissions in a database. If you want submissions saved online, connect a form service or add a server-side form handler later.

UPLOAD TO GODADDY CPANEL
1. Sign in to GoDaddy and open your Web Hosting product.
2. Select Manage, then open cPanel Admin.
3. In cPanel, open File Manager.
4. Open the public_html folder (or the document root for the domain you want to use).
5. If this is a new website, make a backup of any existing files before replacing anything.
6. Upload AWA-Website.zip into the correct document root.
7. Select the ZIP and choose Extract. Make sure index.html is directly inside public_html, not inside an extra nested folder.
8. Visit your domain and test the navigation, both languages and the contact form.

CUSTOMIZE BEFORE LAUNCH
- Confirm the organization's official email address.
- Add the official Instagram/Facebook links if desired.
- Replace the “new gatherings are on the way” event note with confirmed event details when available.
- Add any official mailing address, board details or nonprofit registration wording only after confirming the exact information.

LANGUAGE
The SQ button switches the visible website copy to Albanian; EN switches it back to English.
